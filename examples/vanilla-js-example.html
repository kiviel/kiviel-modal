Kiviel Modal Vanilla JS

Ejemplos de uso de la versión independiente de jQuery. Modales ligeros, animados y con soporte para múltiples instancias.

Uso Básico

API Principal

Usa KivielModal.open(contenido, tamaño, opciones) para abrir un modal.
Tamaños disponibles: 'xs', 'sm', 'md', 'lg'

Modal Simple

Abre un modal con contenido HTML básico.

Modal con Formulario

Modal conteniendo un formulario interactivo.

Modal con Callback

Ejecuta código cuando el contenido se carga.

Tamaños de Modal

Extra Pequeño (xs)

Máximo 400px de ancho. Ideal para alertas rápidas.

Pequeño (sm)

Máximo 600px de ancho. Tamaño predeterminado.

Mediano (md)

Máximo 900px de ancho. Para formularios amplios.

Grande (lg)

Máximo 1200px de ancho. Para tablas y contenido extenso.

Múltiples Modales

Modales Apilables

Kiviel Modal soporta múltiples modales abiertos simultáneamente. Cada nuevo modal se posiciona encima del anterior con z-index incrementado. Presiona ESC para cerrar el modal superior.

Modal Anidado

Abre un modal que puede abrir otro modal encima.

Cerrar Todos

Cierra todos los modales abiertos de una vez.

Ver Estado

Muestra información sobre los modales activos.

Actualización Dinámica

Actualizar Contenido

Abre un modal y actualiza su contenido dinámicamente.

Contenido AJAX

Carga contenido desde el servidor vía fetch().

Ejecución de Scripts

Scripts Automáticos

Kiviel Modal ejecuta automáticamente los scripts <script> incluidos en el contenido del modal. Esto es crucial para contenido AJAX que necesita inicializar plugins o ejecutar lógica JavaScript.

Modal con Script Inline

El script dentro del modal se ejecuta automáticamente.

Ejemplos de Código

// Abrir modal simple const modalId = KivielModal.open('<p>Hola Mundo</p>', 'sm'); // Abrir modal con callback KivielModal.open(contenido, 'md', { onContentLoaded: function(modalBody, id) { console.log('Modal cargado:', id); } }); // Actualizar contenido de un modal existente KivielModal.updateContent(modalId, '<p>Nuevo contenido</p>'); // Cerrar el último modal abierto KivielModal.close(); // Cerrar un modal específico por ID KivielModal.closeById(modalId); // Cerrar todos los modales KivielModal.closeAll(); // Verificar si hay modales abiertos if (KivielModal.exists()) { ... } // Obtener cantidad de modales activos const count = KivielModal.count(); // Obtener información de z-index const info = KivielModal.getZIndexInfo();

Estado Actual de Modales

Haz clic en "Ver Estado" para actualizar
